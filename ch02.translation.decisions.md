# Translation Decisions: ch02 — Storage Types and Relational Stores

## General Principles

> **Analogy/simile clause order**: In Chinese, 就像……一样 (just like…) reads more naturally **after** the main point, not before it. English often inserts the comparison mid-sentence; Chinese prefers: [main statement]，就像……一样。

> **Cross-domain terminology research**: When no established database-specific Chinese translation exists for a term, search related computing fields (I/O, parallel computing, ML frameworks, etc.) for consistent Chinese usage patterns. Also check the author's academic and professional background — technical terms often reflect the author's domain of origin (e.g., HPC, systems programming), which helps identify the most appropriate Chinese equivalent across fields.

1. **Preserve all HTML structure**: Tags, IDs, `data-type` attributes, `<a contenteditable>` indexterm anchors, cross-reference `href` values, and image `src` paths are kept verbatim.
2. **Term introduction**: On first occurrence, a key term is rendered as `<em>中文术语</em>` mirroring the source `<em>` tag. The English acronym or name is retained in parentheses where disambiguation is needed (e.g., `抽象语法树（AST）`).
3. **Subsequent mentions**: Chinese only, no parenthetical repetition.
4. **Code elements**: `SELECT`, `INSERT`, `UPDATE`, `DELETE`, `GROUP BY`, `ORDER BY`, `JOIN` and similar SQL keywords are left unchanged inside `<code>` tags.
5. **Proper nouns / brand names**: MySQL, PostgreSQL, MariaDB, Oracle, Microsoft SQL Server, IBM Db2, SAP HANA, MD5, SHA-256, JSON, XML, jsonb left unchanged.
6. **Chapter/section cross-references**: `<a data-type="xref">` inner text (e.g., `#ch10_aws_storage_services_...`) kept as-is; the publishing system resolves these automatically.

All terms in this section are sourced from the official Chinese translation of *Database System Concepts* (数据库系统概念, Silberschatz et al., 6th ed.), confirmed via https://blog.csdn.net/m0_62083249/article/details/128459038. Classification: **official (other source)**.

| English | Chinese |
|---------|---------|
| query processor | 查询处理器 |

| query optimizer | 查询优化器 |

| execution plan / query plan | 执行计划 |
| execution engine | 执行引擎 |
| storage engine | 存储引擎 |

| cache manager | 缓存管理器 |
