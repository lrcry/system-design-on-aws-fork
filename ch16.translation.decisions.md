## Core Domain Terminology

### newsfeed / user timeline
- **newsfeed** → **信息流（动态流）**
  - Rationale: "信息流" is the standard Chinese term used by WeChat, Weibo, and other Chinese social platforms. "动态流" is used as a parenthetical clarification. Avoided "新闻推送" which implies broadcast news rather than social feed.
- **user timeline** → **用户时间线**
  - Rationale: Direct, widely-understood calque. Used consistently throughout Chinese developer communities.

### post / like / comment / follower / following
- **post** (noun) → **帖子**
  - Rationale: Standard term in Chinese social media contexts. More natural than "发布内容" or "动态".
- **like** (action/noun) → **点赞**
  - Rationale: Industry-standard Chinese social media term.
- **comment** → **评论**
- **follower** → **粉丝**（in social context）/ **关注者**（in technical/neutral context）
  - Used "粉丝" when describing social dynamics, "关注者" in data schema descriptions for precision.
- **following** (list of people a user follows) → **关注列表** / **正在关注**

### Push mechanism / Pull mechanism / Hybrid
- **push mechanism** → **推送机制（写时扇出）**
  - Added parenthetical clarification "写时扇出" to help technical readers understand the fan-out-on-write pattern.
- **pull mechanism** → **拉取机制（读时拉取）**
- **hybrid approach** → **混合方案**

### fan-out
- **fan-out** → **扇出**
  - Rationale: Standard technical CS term in Chinese. Distinct from "enhanced fan-out (EFO)" for Kinesis, which was already in glossary #333.

## Specific Rendering Decisions

1. **Section cross-references**: All `<a data-type="xref">` links preserved verbatim; translated surrounding text only.
2. **Code blocks**: All `<pre data-type="programlisting">` content kept verbatim (DynamoDB schema notation, Redis commands).
3. **Figure captions**: Translated to Chinese.
4. **Table captions and headers**: Translated.
5. **HTML index terms** (`<a data-type="indexterm">`): All attributes (`data-primary`, `data-secondary`, etc.) preserved in English as they are index metadata for the publishing system.
6. **External hyperlinks**: All URLs kept unchanged; link anchor text translated.
7. **`keep-together` spans**: Preserved verbatim.
8. **Product/brand names embedded in text**: Amazon, Twitter, X, Instagram, LinkedIn, Facebook, Redis, PostgreSQL, MySQL, Cassandra, Keycloak, FlockDB, Gizzard, Manhattan, Unicorn, Haystack, Memcached, LIquid, EarlyBird, Snowflake — all kept in English.
