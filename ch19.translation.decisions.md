# Translation Decisions: ch19 — Designing a Chat Application

## General Approach

This chapter covers the design of a large-scale chat application (WhatsApp-style), including messaging protocols, the Actor model, Erlang/Ejabberd architecture, and AWS deployment. The translation follows conventions established in prior chapters and the ch19 glossary (entries #737–764).

---

## Chapter Title

- **"Designing a Chat Application"** → **"设计聊天应用"**
  - 聊天应用 is the standard Chinese term for a chat/messaging application. "即时通讯应用" was considered but 聊天应用 is more concise and widely used.

## Key Term Translation Decisions

### Messaging Application Types
- **one-to-one messaging** → **一对一消息** — Direct, widely understood
- **group messaging** → **群组消息** — Standard term in Chinese messaging apps
- **broadcast messaging / broadcast channel** → **广播消息 / 广播频道** (glossary #749) — 广播 is the standard Chinese term for broadcast

### User Status Features
- **read receipts** → **已读回执** (glossary #750) — 已读回执 is the standard term used in Chinese messaging apps (WeChat uses this)
- **last seen** → **最后在线时间** — Descriptive and natural; preferred over literal "最后看到"
- **user presence status** → **用户在线状态** — Standard

### Security
- **end-to-end encryption** → **端到端加密** (glossary #751) — This is the standard Chinese translation used in official documentation (zh.wikipedia, security publications). Note: "端对端加密" also exists but "端到端加密" is more commonly used.

### Actor Model
- **actor model** → **Actor 模型** (glossary #737) — The standard Chinese technical translation; Wikipedia zh uses "Actor模型"
- **actor** (individual) → **Actor** (kept in English in the first occurrence with explanation, then as "Actor") — Product names/technical concepts without established Chinese equivalents keep English form
- **supervisor actor** → **监督 Actor** — Hybrid term common in Chinese technical writing
- **mailbox (actor)** → **邮箱** — Direct, natural analogy translation

### Erlang/Ejabberd
- **Ejabberd** → **Ejabberd** (glossary #738) — Proper name, no Chinese translation
- **Erlang** → **Erlang** (glossary #739) — Programming language name, kept in English
- **BEAM (Bogdan's Erlang Abstract Machine)** → **BEAM（最初称为 Bogdan 的 Erlang 抽象机）** (glossary #740) — The full name is given in Chinese on first mention
- **Erlang processes** → **Erlang 进程** — Mixed term, Erlang kept as-is
- **hot-swap deployment** → **热更新部署** (glossary #745) — 热更新 is the widely used Chinese term; 热部署 also acceptable but 热更新部署 is more specific
- **Mnesia** → **Mnesia** (glossary #741) — Proper name, kept as-is
- **ETS (Erlang term storage)** → **Erlang 词项存储（ETS）** (glossary #742)
- **JBOD (Just a Bunch of Disks)** → **JBOD（Just a Bunch of Disks，磁盘组合）** (glossary #743) — Acronym kept, Chinese description added
- **append-only file (AOF)** → **仅追加文件（AOF）** (glossary #744)
- **islands (Erlang)** → **数据岛（island）** (glossary #761) — 数据岛 conveys the concept naturally
- **gen_server** → **gen_server** (glossary #762) — Technical module name kept in English
- **YAWS (Yet Another Web Server)** → **YAWS（Yet Another Web Server）** (glossary #748) — Kept as-is with English expansion, no standard Chinese name
- **chat daemons** → **聊天守护进程** — 守护进程 is the standard translation for daemon
- **web daemons** → **Web 守护进程**

## Structural Decisions

1. **Index terms (`data-type="indexterm"`)**: All index terms preserved as-is with English `data-primary`/`data-secondary` attributes unchanged, as these are used for book indexing infrastructure.

2. **Cross-references (`data-type="xref"`)**: All cross-references preserved as-is pointing to original chapter IDs.

3. **Figure captions**: Translated to Chinese.

4. **Table captions and headers**: Translated to Chinese.

5. **Note boxes**: Content translated; `data-type="note"` attribute preserved.

6. **Code-style terms**: Technical names (Ejabberd, Erlang, BEAM, gen_server, etc.) preserved in their original form within translated text.

7. **Numbers in equations**: Formatted consistently (e.g., "30 亿" for 3 billion following Chinese convention for large numbers).
