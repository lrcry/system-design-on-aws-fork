## Key Translation Decisions

### 1. AWS Service Names
AWS service names are kept in English on first occurrence and in subsequent occurrences, consistent with AWS's own Chinese documentation conventions. For example:
- "Amazon VPC" remains "Amazon VPC"
- "AWS Transit Gateway" remains "AWS Transit Gateway（中转网关）" on first occurrence, then "Transit Gateway"
- "Amazon CloudFront" is translated as "亚马逊 CloudFront" (following the glossary #125)
- "Amazon API Gateway" remains "Amazon API Gateway"
- "AWS Direct Connect" remains "AWS Direct Connect"

### 2. Technical Standards Terminology
- "hub-and-spoke" → "轮辐型（hub-and-spoke）": The English term is kept in parentheses as this is a well-known networking topology name.
- "stateful" / "stateless" → "有状态" / "无状态": Standard Chinese networking terms.
- "on-premises" → "本地部署": This is the widely accepted Chinese translation.
- "soft limit" → "可调整上限（软性限制）": More descriptive Chinese equivalent.

### 3. IP Address Terminology
- "network ID" / "host ID" kept with their English abbreviations as they appear in technical figures.
- "binary octet" not explicitly translated; parenthetical "(binary octet)" omitted for naturalness.
- IP address classes A/B/C translated as "A 类 / B 类 / C 类".

### 4. Chapter-Specific Conventions
- "Cafe Delhi Heights" (the running analogy throughout the chapter) is kept in its original English name as it is a proper noun and appears repeatedly as an analogy anchor.
- "p99.99 latency" kept as-is — technical metric notation retained.
- "802.1Q VLAN" kept as-is — technical standard notation.
- "EUI-64" kept as-is.

### 5. First-Occurrence Parenthetical Policy
- On first occurrence of a major term, both English and Chinese are provided: e.g., "Amazon VPC（虚拟私有云）", "无类别域间路由（CIDR）", "责任共担模型".
- Subsequent occurrences use only the primary Chinese form or the established abbreviation.

### 6. Table Headers
All table headers are translated into Chinese. Data values (IP address ranges, port numbers, protocol names like TCP/UDP, rule actions like "Allow/Deny") are translated where the context is Chinese-readable, but kept in English where they are universal technical notations (e.g., "0.0.0.0/0", "igw-id").

### 7. "Soft limit" note box
The note about soft limit is translated with "可调整上限（软性限制）" to convey that this is a limit that can be raised, which is the functional meaning.

### 8. Source Text Correction
- The source English text (line 71) states "Class D is reserved for multitasking" — this appears to be a typo in the original; Class D is universally reserved for **multicasting**, not multitasking. The Chinese translation correctly uses "多播" (multicast) rather than literally translating the apparent error.

### 9. Ambiguous Terms
- "tenancy" → "租赁" (rental/lease): AWS documentation uses "专用租赁" for dedicated tenancy. The word "租赁" (lease) is used rather than "租用" for consistency with AWS's own Chinese documentation.
- "listeners" in ELB context → "监听器": Standard AWS Chinese documentation term.
- "target groups" → "目标组": Standard AWS Chinese documentation term.
