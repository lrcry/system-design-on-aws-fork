## 术语翻译决策

### 1. Amazon SNS 无官方中文品牌名

**原文**：Amazon Simple Notification Service (SNS)
**译文**：Amazon Simple Notification Service（SNS）
**决策**：经查询 AWS 中国官方文档，SNS 未见统一的中文品牌名（不同于 SQS 有"亚马逊简单队列服务"的官方中文名）。本章全程保留英文服务名，首次出现时不附加中文全称。
**类型**：AWS official（无中文品牌名）

---

### 2. Amazon States Language (ASL) 保留英文

**原文**：Amazon States Language (ASL)
**译文**：Amazon States Language（ASL）
**决策**：AWS 中国官方文档存在机器翻译错误"亚马逊各州语言"——此处"states"指状态机的状态（state），非美国地理上的"州"（state）。该机器翻译结果已被明确拒绝。保留英文原名以确保准确性；在正文说明 ASL 是基于 JSON 的结构化语言即可。
**类型**：AWS official（保留英文）

---

### 3. KDA / KDF 服务更名处理

**原文**：Amazon Kinesis Data Analytics (KDA) / Amazon Kinesis Data Firehose (KDF)
**决策**：
- KDA 已更名为"适用于 Apache Flink 的亚马逊托管服务"（Amazon Managed Service for Apache Flink）。
- KDF 已更名为"Amazon Data Firehose"（去掉了"Kinesis"前缀）。
本章原文仍使用旧名称，为尊重原书内容并保持可读性，翻译中沿用原书的旧名（KDA、KDF），不主动替换为新名称。更名信息已记录于词汇表（glossary.md #329、#330）。
**类型**：翻译约定

---

### 4. 状态机状态类型名称保留英文

**原文**：Pass / Task / Choice / Wait / Succeed / Fail / Parallel / Map
**译文**：保留英文原名（Pass / Task / Choice / Wait / Succeed / Fail / Parallel / Map）
**决策**：这些是 AWS Step Functions 中 Amazon States Language 定义的状态类型名称，属于技术专有名词，在 ASL JSON 定义中以英文出现。中文文档惯例同样保留英文，避免混淆。正文描述部分配有中文说明。
**类型**：AWS official（技术名词保留英文）

**类型**：non-official（参考行业译法）

### 14. "Delegation" 的译法

**原文**：delegation（trust policy / permissions policy）
**译文**：委派权限（信任策略；权限策略）
**决策**：AWS 官方中文文档将"delegation"译为"委派"或"委托"，本章结合上下文使用"委派权限"以更准确地描述信任策略和权限策略的组合概念。
**类型**：AWS official

### 19. 首次出现服务名的处理方式

本章遵循各已翻译章节（ch02～ch10）确立的惯例：
- 带有官方中文名的服务：首次出现时以"中文名（英文名）"格式呈现，例如"亚马逊简单队列服务（Amazon SQS）"。
- 无官方中文名的服务：首次出现时保留英文名，必要时附简短中文说明。
- 后续出现可使用英文缩写或英文全名。
