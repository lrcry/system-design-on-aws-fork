# Translation Decisions: ch10 — AWS Storage Services

## General Principles

1. **HTML structure preservation**: All HTML tags, attributes, `id`s, `data-type`s, `data-primary`/`data-secondary`/`data-tertiary` index term attributes, `data-startref` attributes, `href`s, and `class` attributes are preserved verbatim.
2. **Index term anchors**: All `<a contenteditable="false" data-type="indexterm" ...>&nbsp;</a>` anchors are kept unchanged — their `data-primary`, `data-secondary`, `data-tertiary`, `id`, and `data-startref` attributes remain in English because they are machine-readable identifiers.
3. **Cross-references**: All `<a data-type="xref" href="...">` elements are kept unchanged.
4. **Code blocks**: The JSON sample document inside `<pre data-type="programlisting">` is not translated; it contains field names and data values that are part of a code example.
5. **Figure `alt` text**: The `alt` attribute on figure images is preserved as-is (it was auto-generated English text); only the `<figcaption>` visible text is translated.
6. **Service name strategy**: AWS service names follow the pattern used in ch02.translated.html:
   - First occurrence in each chapter: full Chinese name + English name in parentheses (e.g., "亚马逊弹性块存储（Amazon EBS）")
   - Subsequent occurrences: use the abbreviation or short form (e.g., "EBS")
   - Services with no official Chinese name: keep English name (e.g., "Amazon RDS", "Amazon Aurora", "Amazon DynamoDB", "Amazon DocumentDB", "Amazon Neptune", "Amazon Keyspaces", "Amazon Macie", "Aurora DSQL")
   - Services with partial Chinese branding: "亚马逊 ElastiCache", "亚马逊 OpenSearch 服务", "亚马逊 Timestream", "亚马逊 FSx"

## Notable Decisions

1. **"S3 Glacier Deep Dive" vs "Deep Archive"**: The source text says "S3 Glacier Deep Dive" which appears to be an error in the original (the actual AWS product is "S3 Glacier Deep Archive"). Translated as "S3 Glacier 深度归档" following the actual AWS CN product name, consistent with AWS documentation.

2. **Aurora DSQL**: Announced in late 2024, no Chinese AWS documentation found at translation time. Kept as "Aurora DSQL" with "distributed relational database" translated as "分布式关系数据库".

3. **`<span class='keep-together'>` elements**: These are typesetting hints to the Atlas publishing system. The wrapped text is translated normally; the span tag and class attribute are preserved unchanged.

4. **Cafe Delhi Heights**: Proper noun (restaurant chain name used throughout the book). Kept as-is; not translated.

5. **Lustre**: Third-party high-performance filesystem product name. Kept as-is.

6. **MongoDB**: Third-party database product name. Kept as-is.

7. **Apache TinkerPop Gremlin / openCypher / SPARQL**: Graph query language names (third-party or standard). Kept as-is.

8. **"R5d instances" / "R6gd instance family"**: AWS instance type identifiers. Kept as-is.

9. **Code values in JSON example**: The JSON document sample (Name, orderId, FoodItems, etc.) is code, not prose. No translation applied.

10. **URL links**: All `href` attributes preserved unchanged. Per project convention, we do not modify hyperlinks.
