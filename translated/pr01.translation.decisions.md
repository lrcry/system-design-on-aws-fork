# Translation Decisions: pr01.html

## Overview
The preface written by the authors. Contains sections: How This Book Is Organized, What This Book Isn't, Who Should Read This Book, Conventions Used in This Book, O'Reilly Online Learning, How to Contact Us, and Acknowledgments (with individual author notes).

## Structural Decisions
- HTML comment block (commented-out "Using Code Examples" section) preserved verbatim.
- All `id` attributes, `data-type` attributes, and class names preserved.
- All URLs, email addresses, phone numbers, and ISBNs kept unchanged.
- All proper nouns (person names, company names, institution names) kept in Latin form or given standard Chinese transliterations as noted above.
- Author Wikipedia links in `<a class="orm:hideurl">` tags preserved verbatim.
- Nested `<section data-type="sect2">` structure preserved exactly.
- Production HTML comments preserved verbatim.
