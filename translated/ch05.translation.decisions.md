# Translation Decisions: ch05 — Load Balancing Approaches and Techniques

## Overarching Principles

1. **LB abbreviation**: "LB" and "LBs" are kept as-is throughout the Chinese text, as this abbreviation is universally understood in Chinese technical writing. "Load balancer" is translated as 负载均衡器 on first use.
2. **AWS service names**: Amazon API Gateway, Amazon Route 53, AWS Network Load Balancer (NLB), AWS Application Load Balancer (ALB) retain their English names per AWS convention for Chinese documentation.
3. **Nginx / HAProxy**: Kept in English as these are proper product names with no standard Chinese translation.
4. **L4 / L7**: OSI layer designations (L4, L7) are kept as-is, consistent with Chinese AWS documentation practice.
5. **Code blocks**: All `<pre>` code blocks are left untranslated.
6. **Chapter cross-references**: All internal xref IDs and hrefs are preserved unchanged.
7. **Index terms**: All `<a contenteditable="false" data-type="indexterm" ...>` elements are left intact and untranslated.

## Structural Decisions

- Chapter title 「Load Balancing Approaches and Techniques」→「负载均衡方法与技术」
- Section headings translated literally with some natural Chinese phrasing adjustments
- `<figcaption>` elements are translated
- Definition list `<dt>` terms are translated
- All `<code>` inline elements (like `GET /path`, `POST /path`) are left untranslated
- Note boxes (`<div data-type="note">`) are fully translated
