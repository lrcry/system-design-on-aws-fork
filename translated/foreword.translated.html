推荐序

系统设计是构建可扩展、高可用、高性能且安全的应用程序最重要的方面之一，即便在使用量增长一到两个数量级的情况下也不例外。这正是我认为本书主题如此重要的原因。我欣赏本书的结构安排：从分布式系统中权衡取舍的基础知识讲起，例如 CAP 定理、爆炸半径的量化单位，以及系统设计中的其他常见取舍，然后再介绍如何在实践中运用这些原则。我认为这种方式尤为有益——从核心原则出发，落脚于关键设计决策的实际落地（例如"哪种数据库最适合运行我的工作负载？""我的工作负载最佳缓存策略是什么？""应该选择哪种存储服务？"）。即便 AWS 不断推出新功能，这种思维框架依然能够帮助读者举一反三，使本书所蕴含的概念历久弥新。

对我个人而言，阅读本书令我深深忆起 AWS 早期的岁月——那时我们花了大量时间讨论这些权衡取舍。彼时，CAP 定理、爆炸半径、无缝扩展等概念尚未得到广泛理解，我们围绕这些主题及其内在取舍展开了大量深入的讨论。然而，正是这些讨论，孕育出了一批极为强健的 AWS 服务，如 S3、DynamoDB 等，如今已深受数百万 AWS 用户的喜爱。我希望你能真正领会这些概念，并从中获得启发，打造出同样令人惊艳、让用户爱不释手的产品与服务。

衷心恭喜两位作者完成了这本优秀的著作，也祝所有踏上这段旅程的读者一切顺利！

Swami Sivasubramanian，

AWS 人工智能与数据业务副总裁
