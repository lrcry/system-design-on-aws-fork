# Translation Decisions: ch18 — Designing a Hotel Reservation System

## Key Term Choices

| English | Chinese | Rationale |
|---------|---------|-----------|
| property | 房源 | In the hotel reservation context, "property" refers to a listed accommodation. 房源 (listed property/accommodation) is the standard Chinese platform term used by Airbnb (爱彼迎), Ctrip (携程), and Meituan (美团). Avoid generic 财产 (property/asset) or 物业 (building management). |
| property owner | 房东 / 房源方 | 房东 is the natural colloquial Chinese word for landlord/host. Used 房东 for individual owners and 房源方 when referring to the business entity. |

## Structural Decisions

1. **Section headings**: Translated faithfully. `<h1>`, `<h2>`, `<h3>` tags preserved.
2. **`<figcaption>` text**: Translated concisely to match diagram context.
3. **`<code>` blocks**: Left untranslated (SQL, code identifiers like `HOLD_FOR_ID`, `seat_{theatreId}_{showId}_{seatId}` etc.).
4. **Math/equation blocks** (`<div data-type="equation">`): Units, variable names and formulas preserved in English; narrative labels translated where present.
5. **`<a>` href links**: All URLs preserved as-is; only display text translated where relevant.
6. **`data-type="indexterm"` anchors**: Preserved structurally; not translated (internal index metadata).
7. **`<em>` emphasis**: Preserved; translated text inside.
8. **`<dl>/<dt>/<dd>` definition lists**: Term (`<dt>`) and definition (`<dd>`) both translated.
9. **Company names**: Booking.com, Airbnb, Agoda, Gojek, PayPal, Razorpay kept in English as proper nouns.
10. **AWS service names**: Kept in English per AWS naming convention (confirmed against glossary pattern established in ch02–ch16).
11. **`<pre>` code block**: SQL code left untranslated; preserves original formatting.

## Ambiguous Cases

- **"property"**: In the introduction, the chapter explicitly defines "property" as the term for any place to stay. In Chinese the parallel is 房源 (accommodation listing). This is used consistently.
- **"room"**: Translated as 客房 (hotel room) rather than 房间 (generic room), as this is standard Chinese hotel industry language.
- **"stay"**: Translated as 入住 (check-in/stay at a property) in most contexts, or 住宿 where it refers to the act of staying.
- **"listing"**: 房源挂牌 / 房源列表 — used 房源列表 for search results and 房源 for individual listed items.
- **"pre-RPC / RPC / post-RPC"**: Kept as technical terms. Added brief parenthetical: 远程过程调用（RPC）前 / RPC / RPC 后.
