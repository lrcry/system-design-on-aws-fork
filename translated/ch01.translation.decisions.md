# Translation Decisions: ch01 — System Design Trade-offs and Guidelines


## General Principles (inherited from previous chapters)

1. **Preserve all HTML structure**: Tags, IDs, `data-type` attributes, `<a contenteditable>` indexterm anchors, cross-reference `href` values, and image `src` paths are kept verbatim.
2. **Term introduction**: On first occurrence, a key term is rendered as `<em>中文术语</em>` mirroring the source `<em>` tag. The English acronym or name is retained in parentheses where disambiguation is needed (e.g., `平均故障间隔时间（MTBF）`).
3. **Subsequent mentions**: Chinese only, no parenthetical repetition.
4. **Equations**: `data-type="equation"` blocks with `data-type="tex"` LaTeX are left untouched; only surrounding prose is translated.
5. **Figure/table captions**: Translated in full; `id` attributes and `<img src>` paths kept verbatim.
6. **Chapter/section cross-references**: `<a data-type="xref">` inner text (e.g., `#ch02_storage_types_and_relational_stores_...`) kept as-is; the publishing system resolves these automatically.
7. **Epigraph attributions**: Author names (Brian Kernighan, Albert Einstein, Jeffrey C. Mogul, Butler Lampson, Tom West) are kept in their original Latin-script form; no transliteration, consistent with how other chapters treat named individuals/authors.
8. **Proper nouns / brand names kept in English**: AWS service names follow the standard convention below; third-party/open-source/academic proper nouns (e.g., Dynamo the paper/system) also follow prior-chapter convention of staying in English unless an AWS-official Chinese name exists.
