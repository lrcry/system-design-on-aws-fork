## Key Translation Decisions

### 1. Chapter Title
- **"Big Data, Analytics, and Machine Learning Services"** → **"大数据、分析与机器学习服务"**
- Decision: Standard Chinese industry terminology; "大数据" is universally used in Chinese tech literature.

### 2. AWS Service Names (kept in English)
The following AWS service names are kept in English per AWS naming convention. Their English names appear in AWS Chinese documentation without Chinese substitutes:
- Amazon EMR, AWS Glue, Amazon Athena, Amazon QuickSight, Amazon Redshift, Amazon SageMaker
- Amazon CodeWhisperer, Amazon Comprehend, Amazon Kendra, Amazon Lex, Amazon Forecast
- Amazon Rekognition, Amazon Transcribe, Amazon Polly, Amazon Translate
- AWS Inferentia, AWS Trainium, AWS Neuron SDK
- EMRFS, SPICE, Redshift Spectrum, Redshift Managed Storage (RMS)
- SageMaker Clarify, SageMaker Debugger, SageMaker Pipelines, SageMaker Ground Truth, Data Wrangler

### 3. "Variety, Velocity, Volume" (the 3 Vs of big data)
- **"velocity"** → **"速度（velocity）"** — Left English term in parentheses for clarity in technical context where the 3 Vs are cited.
- Decision: The text mentions "terabytes to petabytes" for volume and "variety" and "velocity" as distinct dimensions. We translated naturally without explicitly translating every term in the implicit 3 Vs reference, following the original text's flow.

### 4. "Primary node / Core node / Task node" (EMR cluster node types)
- **"Primary node"** → **"主节点（Primary node）"**
- **"Core node"** → **"核心节点（Core node）"**
- **"Task node"** → **"任务节点（Task node）"**
- Decision: AWS Chinese documentation uses "主节点", "核心节点", and "任务节点". English terms added in parentheses for technical clarity.

### 5. "bootstrap actions"
- **"bootstrap actions"** → **"引导操作"**
- Decision: AWS official Chinese documentation uses "引导操作" for EMR bootstrap actions.

### 6. "data catalog" (Glue)
- **"data catalog"** → **"数据目录"**
- Decision: AWS Chinese documentation for Glue uses "数据目录" (数据目录 in docs.amazonaws.cn/zh_cn/glue).

### 7. "data crawler" (Glue)
- **"data crawler"** → **"数据爬网程序"**
- Decision: AWS Chinese documentation uses "爬网程序" for Glue crawlers, consistent with #644 in glossary.

### 8. "DPU (Data Processing Unit)"
- **"DPU"** → **"数据处理单元（DPU）"**
- Decision: AWS Chinese Glue documentation uses this phrasing.

### 9. "federated query"
- **"federated query"** → **"联合查询"**
- Decision: AWS Chinese documentation for Athena and Redshift uses "联合查询". Consistent with glossary #646.

### 10. "UDF (user-defined function)"
- **"UDF"** → **"用户定义函数（UDF）"**
- Decision: Standard SQL terminology; AWS Chinese documentation uses "用户定义函数".

### 11. "SPICE (Super-fast, Parallel, In-memory Calculation Engine)"
- **"SPICE"** → **"SPICE（超快速并行内存计算引擎）"**
- Decision: AWS QuickSight Chinese documentation keeps the acronym SPICE and provides a descriptive Chinese name.

### 12. "business intelligence (BI)"
- **"business intelligence"** → **"商业智能（BI）"**
- Decision: Industry-standard Chinese translation; AWS documentation uses "商业智能" for BI.

### 13. "zone maps" (Redshift)
- **"zone maps"** → **"区间映射（Zone Map）"**
- Decision: AWS Redshift documentation in Chinese uses "区间映射"; English term retained in parentheses.

### 14. "sort key" (Redshift)
- **"sort key"** → **"排序键"**
- Decision: AWS Redshift Chinese documentation uses "排序键" consistently.

### 15. "distribution styles" (Redshift)
- **"distribution styles"** → **"数据分布方式"**
- Decision: AWS Redshift Chinese documentation uses "分布方式" or "数据分布方式".

### 16. "materialized views"
- **"materialized views"** → **"物化视图"**
- Decision: Standard database terminology in Chinese; "物化视图" is used in AWS Redshift Chinese documentation.

### 17. "workload management (WLM)"
- **"workload management (WLM)"** → **"工作负载管理（WLM）"**
- Decision: AWS Redshift Chinese documentation uses "工作负载管理（WLM）".

### 18. "Redshift Managed Storage (RMS)"
- **"Redshift Managed Storage (RMS)"** → **"Redshift 托管存储（RMS）"**
- Decision: "托管存储" is standard AWS terminology in Chinese documentation.

### 19. "JDBC / ODBC"
- **"Java Database Connectivity (JDBC)"** → **"JDBC（Java 数据库连接）"**
- **"Open Database Connectivity (ODBC)"** → **"ODBC（开放式数据库连接）"**
- Decision: Standard technical translation. AWS Redshift Chinese documentation uses these forms.

### 20. "machine learning (ML)" and "artificial intelligence (AI)"
- **"machine learning"** → **"机器学习（ML）"** / **"机器学习"**
- **"artificial intelligence (AI)"** → **"人工智能（AI）"** / **"人工智能"**
- Decision: Standard Chinese terms used throughout tech literature and AWS documentation.

### 21. "hyperparameter"

- Decision: Standard ML terminology in Chinese; "超参数" is universally used in Chinese ML literature and AWS SageMaker documentation.

- Decision: AWS SageMaker Chinese documentation uses "自动模型调优".

### 23. "GPU (Graphics Processing Unit)"
- **"GPU"** → **"GPU（图形处理单元）"**

### 24. "FPGA (field-programmable gate array)"

- Decision: Standard Chinese translation confirmed in technical literature and AWS documentation.

### 25. "coprocessor"
- **"coprocessor"** → **"协处理器"**

### 26. "deep learning"
- **"deep learning"** → **"深度学习"**
- Decision: Standard Chinese term used universally in Chinese AI/ML literature.

### 27. "inference (ML)"

- Decision: AWS documentation uses "推理" for ML inference. The note in the text defines it clearly.

### 28. "natural language processing (NLP)"
