## Translation terminology decisions requiring final glossary reconciliation

- **P18, OS boot volume:** Current approved Chinese text is **操作系统启动卷**. In the AWS EC2 context, **根卷** is the canonical AWS documentation term for *root volume*; AWS also uses **根（启动）卷** in its EBS modification documentation. **引导卷** is a familiar alternative in operating-system/Windows materials, but should not automatically replace *root volume*. Review usage throughout all chapters before finalising the shared glossary.
- **P19, network-attached EBS:** Confirmed that EBS is network-attached **block storage**; Amazon EFS is network-accessible **shared file storage**. Do not equate the descriptive phrase “network-attached storage” here with the NAS product category without clarification.

### Supporting technical references and reviewer notes

- [AWS EBS I/O characteristics](https://docs.aws.amazon.com/ebs/latest/userguide/ebs-io-characteristics.html): SSD volumes handle small/random I/O more efficiently than HDD volumes; SSD maximum counted I/O size 256 KiB, HDD 1,024 KiB.
- [AWS EBS volume types](https://docs.aws.amazon.com/ebs/latest/userguide/ebs-volume-types.html): SSD performance is predominantly IOPS; HDD performance predominantly throughput; correct name **Throughput Optimized HDD**; magnetic is previous-generation.
- P21 wording selected after reviewer clarification: “适合处理单次读写数据量较小的 I/O 请求”. Preserve contrast with P22.
- P23 wording selected after reviewer clarification: “例如需要低频访问磁盘数据的场景”; “such as” introduces an example rather than an extra defining condition.
- [EBS Multi-Attach](https://docs.aws.amazon.com/ebs/latest/userguide/ebs-volumes-multi.html).
