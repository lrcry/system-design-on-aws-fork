前言

系统设计是一门严谨的艺术，让我们一起创作大规模的杰作。

System Design on AWS 是一本全面指南，帮助软件架构师和工程师在持续演进的云计算环境中理解、构建并扩展 Amazon Web Services（AWS）云上的复杂系统。本书提供了一套结构化的方法，用以应对 AWS 上真实世界的系统设计挑战。书中内容聚焦于基本原则、架构权衡取舍和实战使用场景，引导你从 Day 0（最小可行产品）走向 Day N（最有价值产品）。通过详尽的章节，本书将 AWS 广泛的服务体系娓娓道来，并阐明如何策略性地加以运用，以满足技术和业务两方面的需求。

本书结构

本书分为三大核心部分：首先建立系统设计的基础知识，然后深入介绍用于构建高弹性架构的核心 AWS 服务，最后以实战系统设计案例收尾。书中涵盖基础系统设计模式、扩展机制、缓存策略、网络协议和部署策略。通过在云计算背景下探讨这些要素，本书为解决各行各业的大规模设计问题提供了一套实用工具集。每个部分的开篇均会列出该部分所包含的章节，请参阅各开篇以了解详细内容。本书旨在帮助你：

  • 扎实掌握系统设计基本原则与权衡取舍

  • 熟练运用核心 AWS 服务及其在构建大规模系统中的作用

  • 深入了解真实世界的使用场景，理解如何在 AWS 上构建和部署可扩展架构

  • 掌握在 AWS 云环境中平衡性能、可扩展性与成本的策略

本书不涉及的内容

本书不提供基础设施部署或应用程序业务逻辑的详细代码实现。相反，本书着重强调架构与设计过程，帮助你理解如何将系统分解为可管理的组件，并做出有据可依的架构决策。

本书的目标读者

本书非常适合希望在 AWS 上构建或扩展应用程序的软件架构师、开发人员、DevOps 工程师和系统架构师。对于正在从本地部署迁移到云基础设施，或致力于借助 AWS 构建大规模应用程序的专业人士而言，本书尤为实用。阅读本书建议具备基本的软件实现知识，并熟悉至少一门编程语言。

本书同样推荐给担任软件开发和 DevOps 领导职务的人士。书中的指导原则将帮助你在系统构建过程中为团队扫清障碍，并做出有据可依的决策。

尽管本书以 System Design on AWS 为题，聚焦于 AWS 云，但我们同样推荐给所有热爱在任何云平台或本地数据中心上构建系统的人，以及一切对系统构建充满好奇的读者。书中讨论的设计与扩展原则不依赖于特定的云服务商。
