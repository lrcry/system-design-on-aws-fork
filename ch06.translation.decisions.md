# Translation Decisions: ch06 — Communication Networks and Protocols

## General Principles

> **Layer-name consistency**: When translating protocol stack layer names, match the most authoritative Chinese-language source for that model. For the TCP/IP model, the "Internet" layer is rendered as 网际层 (following zh.wikipedia.org), not 互联网层 or 因特网层, because 网际层 is the established academic translation for that specific TCP/IP layer concept.

> **Term introduction parenthetical**: English acronyms and retained English names are placed in full-width parentheses （…） immediately after the Chinese term on first occurrence only. Subsequent mentions use the Chinese term alone (no parenthetical repetition).

> **Protocol/technology names with no Chinese equivalent**: When AWS or the broader technical community consistently uses the English name even in Chinese documentation, the English name is retained as-is (e.g., WebSocket, WebRTC, GraphQL, QUIC, XMPP, MQTT). A Chinese expansion is given on first occurrence for acronyms.

1. **Preserve all HTML structure**: Tags, IDs, `data-type` attributes, `<a contenteditable>` indexterm anchors, cross-reference `href` values, image `src` paths, and `class` attributes are kept verbatim.
2. **Term introduction**: On first occurrence, a key term is rendered as `<em>中文术语（EN acronym）</em>` mirroring the source `<em>` tag.
3. **Subsequent mentions**: Chinese only, no parenthetical repetition.
4. **Code blocks**: All content inside `<pre>` elements (ping output, HTTP request/response headers, WebSocket handshake, GraphQL schema/query/mutation examples) is left entirely in English.
5. **Chapter/section cross-references**: `<a data-type="xref">` inner text kept as-is; the publishing system resolves these automatically.
6. **CRUD acronym**: Translated as 增删改查（CRUD）on first occurrence, retaining the English acronym.
