# Translation Decisions: ch20 — Designing a Video-Processing Pipeline for a Streaming Service

## Overview

This document records translation decisions made while translating `ch20.html` into Simplified Chinese. The chapter covers the design of a video-processing pipeline for streaming services (Netflix, Amazon Prime Video, YouTube), including video encoding, quality validation, content indexing, content distribution, and AWS media service deployments.

---

## Key Term Translations

### Chapter Title
- **"Designing a Video-Processing Pipeline for a Streaming Service"** → **"设计流媒体服务的视频处理管道"**
  - "pipeline" translated as "管道" (pipeline/conduit), preferred over "流水线" (assembly-line connotation) in software architecture context.
  - "streaming service" → "流媒体服务" (standard Chinese term for streaming media service).

## Structural Decisions

1. **Chapter title span tag**: The `<span class='keep-together'>` wrapping "for a Streaming Service" in the English H1 was removed in the Chinese translation as the layout requirement does not apply to Chinese text. The full title is rendered in a single `<h1>` tag.

2. **Indexterm anchors**: All `<a contenteditable="false" data-type="indexterm" ...>` elements are preserved exactly as in the original, as these are backend index markers not visible to readers.

3. **Figure captions**: Translated directly; figure IDs and image `src` attributes are unchanged.

4. **Note boxes**: The `<div data-type="note">` structure is preserved; note content is translated.

5. **Cross-references**: All `<a data-type="xref" href="...">` elements are preserved as-is; the text content (which is an internal link placeholder) is left unchanged.

6. **Equation/calculation blocks**: Mathematical content in `<div data-type="equation">` translated, with numeric values unchanged.

7. **Code and product names in emphasis tags**: `<em>` tags containing file extensions (.mp4, .avi, .mov) are preserved as-is.

8. **Netflix Conductor and Maestro**: Kept in English as proper names of open-source projects; GitHub links preserved.

9. **Zipkin and OpenTracing**: Kept in English as proper names of open-source projects.

## Terminology Consistency Notes

- "视频处理管道" is used consistently throughout for "video-processing pipeline".
- "摄取系统" is used consistently for "ingestion system" after first introduction.
- "码率" is consistently used for "bitrate" (not "比特率") after the first occurrence where both are given.
- "编码方案" is consistently used for "encoding recipe".
- "数据块" (data chunk/block) is consistently used for "chunk" in the video context.
- All service names from the Netflix architecture (complexity analysis service, ladder generation service, etc.) are translated consistently as:
  - complexity analysis service → 复杂度分析服务
  - ladder generation service → 阶梯生成服务
  - video upload service → 视频上传服务
  - video inspection service → 视频检查服务
  - video encoding service → 视频编码服务
  - video validation service → 视频验证服务
  - video quality service → 视频质量服务
  - play service → 播放服务
  - steering service → 转向服务
  - cache management service → 缓存管理服务
